Read [docs/agents/audience.md](../../../docs/agents/audience.md) before the first question. Hackblooma’s main builders are high-performing high school girls without a software-engineering background.

Interview me about the product, people, and how the program should work until we reach a shared understanding. Walk down each branch of the design tree, resolving dependencies between decisions one-by-one.

Ask the questions one at a time.

Every question must use everyday language, be about what people should experience (never how to implement it), offer exactly 3 reply options (A / B / C), and include your recommended option with a short why.

Do the technical work yourself. Do not ask about databases, APIs, auth mechanics, schemas, or similar. If a question can be answered by exploring the codebase, explore the codebase instead.
