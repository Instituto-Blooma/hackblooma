# Environment

Where configuration lives for local dev, Railway, and production. Template reference: [.env.example](../.env.example).

## Layers

| Layer        | Purpose                                                                 |
| ------------ | ----------------------------------------------------------------------- |
| `.env.local` | Local Convex URLs (`VITE_CONVEX_*`). Loopback-only on Railway PR        |
| Convex env   | Auth, OAuth, Resend, platform admin allowlist — set by `pnpm run setup` |
| Railway vars | Production cloud Convex, `PUBLIC_APP_URL`, deploy keys                  |

## Environment matrix

| Environment        | Convex backend       | Google auth                         |
| ------------------ | -------------------- | ----------------------------------- |
| Local dev          | Local (anonymous)    | Emulate (default)                   |
| Railway local / PR | Local + Vite proxies | Emulate (default)                   |
| Railway staging    | Cloud                | Emulate unless `AUTH_GOOGLE_ID` set |
| Railway production | Cloud                | Real Google                         |

## Client (`.env.local`)

| Variable                       | Required | Notes                                                             |
| ------------------------------ | -------- | ----------------------------------------------------------------- |
| `VITE_CONVEX_URL`              | Yes      | Convex HTTP API. Local loopback; public `/_convex` is process env |
| `VITE_CONVEX_SITE_URL`         | Yes      | Convex site URL for auth HTTP                                     |
| `VITE_CONVEX_BACKEND_URL`      | PR only  | Loopback API for the Vite proxy (written by setup / `dev:all`)    |
| `VITE_CONVEX_BACKEND_SITE_URL` | PR only  | Loopback site URL for the Vite proxy                              |

On Railway local/PR, `.env.local` stays loopback. `node script/run.mjs dev` exports public `VITE_CONVEX_URL=https://<pr-domain>/_convex` for Vite only — do not persist those HTTPS values in `.env.local`.

## Convex backend env

| Variable                                | Local dev                                              | Production               |
| --------------------------------------- | ------------------------------------------------------ | ------------------------ |
| `SITE_URL`                              | `http://localhost:5173`                                | Public app URL           |
| `CUSTOM_AUTH_SITE_URL`                  | Unset locally; proxied `/_convex_site` on Railway PR   | Usually unset            |
| `AUTH_GOOGLE_EMULATE_URL`               | `http://localhost:4002` or proxied `/google-emulate`   | **Unset** — real Google  |
| `AUTH_GOOGLE_ID` / `AUTH_GOOGLE_SECRET` | Unset in dev                                           | Real OAuth credentials   |
| `RESEND_BASE_URL`                       | `http://localhost:4003` or proxied `/resend-emulate`   | `https://api.resend.com` |
| `RESEND_API_KEY`                        | `re_emulate_test_key`                                  | Real Resend key          |
| `E2E_AUTH_SECRET`                       | Set by `e2e:setup` / E2E stack; cleared on teardown    | **Unset**                |
| `E2E`                                   | Set automatically during E2E runs; cleared on teardown | **Unset**                |
| `PLATFORM_ADMIN_EMAILS`                 | First-setup emulate emails (setup default)             | Your platform admins     |
| `JWT_PRIVATE_KEY` / `JWKS`              | Generated by setup; JWKS keys include RFC 7638 `kid`   | Same                     |

Setup default for `PLATFORM_ADMIN_EMAILS` is `dev@example.com,admin@example.com,platform@example.com,testuser@gmail.com` so Google emulate's Dev User, Platform Admin, and built-in Test User can sign in after first setup.

Do not reference `CUSTOM_AUTH_SITE_URL` from `auth.config.ts` — Convex requires every auth-config env var to be set, and this one is PR-only.

## Railway proxy paths (PR preview)

When `PUBLIC_APP_URL` or `RAILWAY_PUBLIC_DOMAIN` points at Railway, setup and Vite proxy:

- `/_convex` → local Convex API
- `/_convex_site` → Convex site / auth callbacks
- `/.well-known/oauth-*` → Convex site (strips `/_convex_site` path insertion)
- `/google-emulate` → Google OAuth emulator
- `/resend-emulate` → Resend emulator
- `/_dashboard` → Convex dashboard UI (`/api/current_deployment` is rewritten to `/_convex`)

`/_dashboard` is available when `dev:all` is running. Anyone with the preview URL can open it. Staging and production use [dashboard.convex.dev](https://dashboard.convex.dev).

## Setup scripts

`pnpm run setup` (`script/setup.mjs`) configures Convex env for local and PR preview. Convex 1.43+ uses `convex init` then `dev --once` (the `--local` flag was removed).

`pnpm run prefetch:convex:local` downloads the Convex local backend + dashboard into `~/.cache/convex` so Railway/CI do not fail on GitHub release redirects.

`pnpm run e2e:setup` seeds fixtures and pushes E2E-only Convex env (including programmatic auth) before Cypress. Prefer `E2E_AUTH_SECRET` from the environment; the local default is `local-e2e-secret`.
